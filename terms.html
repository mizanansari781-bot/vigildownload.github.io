P2P Architecture and Local Storage Disclosures

Privacy-First Architecture: Zero Activity Logs on Cloud Servers

Detailed monitoring logs are never uploaded to, retained by, or processed on Vigil Studio cloud servers.

You acknowledge and understand the operational structure of the software:

  • Child Device Offline: When the Child Device has no internet connection, all activity logs (screen time, app launches, browser history) are stored exclusively in the local sandboxed database of the Child Device.
  • Parent Device Offline: When the Child Device is online but the Parent Device is unreachable, logs continue to be stored safely on the Child Device. Only the device “Last Seen” timestamp (and Last Known Location if Auto-Location is active) is posted to the server.
  • Direct P2P Synchronization: Activity logs sync directly from Child Device to Parent Device over an encrypted P2P session once both devices connect. Once synced, historical activity records reside solely on the Parent Device.
  • Data Loss Risk: Because Vigil Studio does not keep cloud backups of your child’s logs, if the Parent Device is lost, damaged, wiped, or uninstalled, previously synced logs cannot be restored by Vigil Studio.
